# EgressSim

EgressSim is a 2D emergency evacuation simulator designed to explore how differences in people's knowledge and behavior can affect evacuation outcomes.

The simulator will allow users to create controlled evacuation scenarios by defining building layouts, exits, hazards, and simulated agents. Agents can have different characteristics and information, allowing evacuation scenarios to be compared under different conditions.

## Tech Stack

- **Python** — Simulation engine, agent behavior, movement, and pathfinding
- **FastAPI** — Backend API
- **Next.js / TypeScript** — Web application
- **PixiJS** — 2D visualization
- **Pytest** — Automated testing
- **GitHub Actions** — Continuous integration

## Development Setup

Install the project dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the test suite:

```bash
python -m pytest
```
